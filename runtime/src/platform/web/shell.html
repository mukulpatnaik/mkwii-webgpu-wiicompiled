    Help
    
    
    Low FPS, stutter, a crash or a disconnect? Press Save log straight after it
      happens, then DM the file to hiemal on Discord with a few words about what you saw.
    
    
    
    
    Adds a CPU profile to the log so slowdowns can be traced back to the
      game code. It runs an extra background thread: no difference on a fast computer, but it can cost a
      little speed on one with few CPU cores, so turn it off once you have sent the log. Changing it
      reloads the page.
